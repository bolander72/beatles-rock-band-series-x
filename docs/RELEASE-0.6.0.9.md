First community launcher preview for **The Beatles: Rock Band** on Xbox Series X Developer Mode, powered by Xenia.

**Download `The-Beatles-Rock-Band-0.6.0.9-x64.zip` to install.** The large `corresponding-source.tar.gz` asset is optional source for auditing/rebuilding; players do not need it for installation. No game files, music, charts or DLC are supplied.

The bundle includes the signed x64 APPX, Microsoft x64 runtime dependency, Mac/browser installation guide, and a local helper for preparing your own extracted game files for transfer. The tile/app display name is **The Beatles: Rock Band**.

For a persistent Game default, enable **Device Portal → Settings → Preference → Treat UWP apps as games by default**, leave it on, and restart if prompted. An app installed earlier as App may need one final **Details → Game** correction. Complete local player setup once and select Play; later cold launches can open the remembered game directly. Calibrate audio/video in the game for your TV and speakers. Developer Mode remains required.

This is a preview: automated Windows checks, package/source integrity checks, runtime dependency checks and app registration have passed. **The first console Play attempt stopped on a solid blue screen during early startup. This draft is held for investigation; direct-launch, repeated-launch and new-build gameplay checks have not passed.** The underlying 0.6.0.7 build was played on Series X with one Xbox Riffmaster, including working whammy and ordinary tilt. Two guitars, drums, microphones and full-band play are unverified.
